# rglauncher

# RGminer для HiveOS

Скрипт подключает риг к дашборду [rgminer.net](https://rgminer.net) через локальный полётный лист. Работает без доступа к панели HiveOS.

## Запуск

Создайте токен в аккаунте RGminer, скачайте `rghive.sh` на риг и выполните:

```bash
sudo bash rghive.sh -t ВАШ_ТОКЕН -y
```

В консоли root можно убрать `sudo`. Выдавать файлу права на выполнение не нужно. Требуется Python 3.6+.

Скрипт:

1. Сохраняет копию текущего полётника.
2. Останавливает работающий майнер и проверяет, что его процессы завершились.
3. Прописывает RGminer с вашим токеном и запускает его средствами HiveOS.

Совместимые кошелёк и пул переносятся из текущего полётника. Если перенести их нельзя, используются заглушки. Тогда откройте дашборд, задайте монету, кошелёк и пул и примените настройки. До этого хешрейт может быть нулевым.

Чтобы сразу использовать заглушки, добавьте `--setup-only`. Сохранённые настройки дашборда могут примениться автоматически и перекрыть параметры полётника.

## Проверка без изменений

```bash
sudo bash rghive.sh -t ВАШ_ТОКЕН --dry-run
```

## Вернуть прежний полётник

```bash
sudo bash rghive.sh --restore -y
```

Резервные копии хранятся в `/hive-config/rgminer-setup/`. Восстановление полётника не сбрасывает настройки, сохранённые в дашборде.

После восстановления связи HiveOS может прислать свой облачный полётник. Добавьте токен и в него, чтобы сохранить подключение к RGminer.
